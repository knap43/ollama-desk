# Ollama Desk

Chat with local [Ollama](https://ollama.com) models from your desktop and your phone.

| Folder | What it is |
| --- | --- |
| [`ollama-desk/`](ollama-desk) | The GNOME desktop app — Python, GTK 4 and libadwaita, with an agent mode that can act on your desktop. |
| [`ollama-desk-remote/`](ollama-desk-remote) | The Android companion — Kotlin and Jetpack Compose; chat, approve agent actions, manage models and scheduled tasks over your home network. |

Each folder has its own README with build and install instructions.
